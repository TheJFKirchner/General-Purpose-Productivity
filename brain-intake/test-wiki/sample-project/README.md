# Sample project: Client A stop-loss renewal pack

A sample project folder for trying the brain skills. It is not a wiki page; it sits outside `personal/` and `team/`.

- Goal: build the stop-loss and trend sections of Client A's 2027 renewal pack: exposure, lasered members, reimbursement lag, two attachment-point options, and cost trend.
- Data: claims-header (paid amounts), member eligibility, the carrier's laser list.
- `braincite.md` lists the wiki pages and sections this project draws on, in a Team table and a Personal table, each with a reason to read it.
