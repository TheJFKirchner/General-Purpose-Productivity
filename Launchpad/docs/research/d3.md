# D3 (vendored, Visualizer)

- Used for: one of the Visualizer's always-available charting libraries (show_visuals library "D3", key `d3`). Vendored as `app/vendor/d3.min.js` 7.9.2 (ISC, `app/vendor/D3-LICENSE`); inlined into the sealed visual frame as the global `d3`
- Source: `npm pack d3@7.9.2`, tarball checked against the registry's `dist.integrity` (hashes in app/vendor/README.md)
- Links: https://d3js.org/getting-started · https://d3js.org/d3-hierarchy/pack · https://www.npmjs.com/package/d3
- Gotchas
  - The data loaders (`d3.csv`, `d3.json`, ...) fetch over the network: the frame CSP blocks them and app/visuals.py rejects a fragment that calls them
  - d3-dsv's row parser uses `new Function` (only when parsing CSV text); the frame has no `unsafe-eval`, so avoid `d3.csvParse` with objects
  - Size the SVG with a `viewBox` and `width: 100%` so it fits the panel and the enlarge view
  - Do not write "d3.csv" style names in agent files: agentlib's file-reference check flags them as files the agent cannot read
