An overview for colleagues

Cosmo

Cosmo is a set of skills, helpers and ready-made parts for AI assistants. It works with Claude Code and with Cursor. It helps you turn data and notes into reports, decks and dashboards, and it keeps what your team learns in one shared place.

The three ideas → What you need

A few words first

Four terms you will see on every page

None of this needs coding knowledge. These are the only terms you need to follow the rest of the site.

In plain terms

AI assistant: a chat tool, such as Claude Code or Cursor, that can read files, follow steps and write things for you.

In plain terms

Skill: a short written guide the assistant follows for one kind of job, such as building a slide deck.

In plain terms

Subagent: a helper the assistant starts for one focused job. It gets a short brief, does the job and reports back.

In plain terms

Design library: a folder of ready-made charts, tables and slides that deliverables are built from.

The three ideas

Cosmo rests on three ideas

Each idea has its own page. Start with whichever matters most to you.

01

Deliverables made from reusable parts

Reports, decks and dashboards are put together from tested parts in a shared design library. Each new piece starts from something that already works, and they all look alike.

Read about deliverables →

02

A shared memory called the brain

The brain is a folder of plain notes, some personal and some for the team. The assistant reads the useful pages before it starts, and files new facts afterwards, but only with your yes.

Read about the brain →

03

Orchestration with subagents

For bigger jobs, the main assistant splits the work and hands each part to a subagent. It then checks what comes back and puts it together.

Read about orchestration →

How it fits together

One request, start to finish

You ask in plain words. The assistant picks the right skill, checks the brain, and uses helpers and ready-made parts to build the result.

Before you start

Who it is for, and what you need

Who it is for

  • Anyone who uses Claude Code or Cursor at work.
  • People who make reports, slide decks or dashboards from data.
  • Teams that want what they learn kept in one place, not only in people's heads.
  • Newcomers too. You do not need to code to read these pages or to ask for a deliverable.

What you need

  • Claude Code or Cursor, signed in.
  • The Cosmo folder, copied into your assistant's settings folder. A setup page is coming.
  • Python and Node.js. Some skills use them to build reports, decks and dashboards.
  • Edge or Chrome, so the assistant can look at the pages it makes.
  • A folder of notes for the brain. Optional at first.
