# Evernorth Light

- `data-theme="evernorth-light"`
- look: white side menu, teal band, deep-teal text
- page ground stays light ("dark" = darker band + colored menu, not a dark page)
- card top bars: status (green/orange top bar per card)
- stacked-chart palette: 5 distinct: deep teal, teal, mint, lime, amber
- files: `tokens.css` (page) + `chart.js` (charts). nothing else differs from other themes
- color source: approximation (teal family); no published values found; not official. to make official: edit these two files only
