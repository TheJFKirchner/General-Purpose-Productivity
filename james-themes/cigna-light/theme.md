# Cigna Light

- `data-theme="cigna-light"`
- look: white side menu, brand-blue band, navy text
- page ground stays light ("dark" = darker band + colored menu, not a dark page)
- card top bars: status (green/orange top bar per card)
- stacked-chart palette: 5 distinct: navy, blue, cyan, green, amber
- files: `tokens.css` (page) + `chart.js` (charts). nothing else differs from other themes
- color source: third-party logo readings (blue #0033FF, green #03CC54); not official. to make official: edit these two files only
