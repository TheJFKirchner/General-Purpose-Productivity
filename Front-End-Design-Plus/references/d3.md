# D3 recipes

This session draws charts with D3 v7 (a local copy; no network).

## Contract
- Your `code` is the body of `function render(el, rows, lib)`.
- `lib` is the `d3` global. `el` is an empty box already sized by the page; `rows` is every row of the real table.
- Mount: `lib.select(el).append('svg')`.
- Size: read `const W = el.clientWidth || 600, H = el.clientHeight || 360;`, draw in that coordinate space and set `viewBox` to `0 0 W H` with `width` and `height` at `100%`.
- Resize: the `viewBox` scales the drawing with the box. Do not redraw from a ResizeObserver (it can loop).

## Conventions
- Aggregate from `rows` inside the recipe (`lib.rollups`, `lib.sum`, `lib.group`). Never type data values, category lists or totals into the code.
- Values may arrive as strings: coerce with `Number(r.col) || 0`. Dates are ISO text: `String(r.date).slice(0, 7)` gives the month; parse with `lib.utcParse('%Y-%m-%d')` and use `lib.scaleUtc`.
- No transitions: they flicker when cards redraw.
- No network: no `lib.csv`, `lib.json` or other loaders; the data is already in `rows`.
- Leave margins for axes (about 64 left, 36 bottom). Remove axis domain lines and draw light grid lines instead.
- Stack the top in bands so nothing collides: title baseline at y 20, legend (if any) at y 40, plot from `m.top` of at least 56 (about 64 with a legend). Value labels sit at most 6 px above a bar, so they stay below `m.top - 18` and clear of the title.
- Tooltips: append a `<title>` to each mark.
- One clear message per chart; a legend only when colour encodes a field.

## Default look (conservative, blue-led)
- Palette, in order: `#1F4E79`, `#2E75B6`, `#5B9BD5`, `#9DC3E6`, `#44546A`, `#8497B0`, `#A5A5A5`, `#D6DCE5`.
- Text `#333F4F`; grid lines `#E5E9F0`; font `Segoe UI, Arial, sans-serif`.
- A style note from the user overrides these. For dark, fill a background `rect` (for example `#1B2533`), light text and lighter blues first.

## Starter recipe (revenue by region)
```js
const PALETTE = ['#1F4E79', '#2E75B6', '#5B9BD5', '#9DC3E6', '#44546A', '#8497B0', '#A5A5A5', '#D6DCE5'];
const data = lib.rollups(rows, v => lib.sum(v, r => Number(r.revenue) || 0), r => r.region)
  .map(([key, value]) => ({ key, value }))
  .sort((a, b) => b.value - a.value);
const W = el.clientWidth || 600, H = el.clientHeight || 360;
const m = { top: 56, right: 16, bottom: 36, left: 64 };
const svg = lib.select(el).append('svg')
  .attr('viewBox', `0 0 ${W} ${H}`).attr('width', '100%').attr('height', '100%')
  .style('font-family', 'Segoe UI, Arial, sans-serif').style('color', '#333F4F');
svg.append('text').attr('x', 4).attr('y', 20)
  .attr('font-size', 14).attr('font-weight', 600).attr('fill', '#1F4E79')
  .text('Revenue by region');
const x = lib.scaleBand().domain(data.map(d => d.key)).range([m.left, W - m.right]).padding(0.3);
const y = lib.scaleLinear().domain([0, lib.max(data, d => d.value) || 1]).nice().range([H - m.bottom, m.top]);
svg.append('g').attr('transform', `translate(0,${H - m.bottom})`)
  .call(lib.axisBottom(x).tickSizeOuter(0));
svg.append('g').attr('transform', `translate(${m.left},0)`)
  .call(lib.axisLeft(y).ticks(5).tickFormat(lib.format('~s')).tickSize(-(W - m.left - m.right)))
  .call(g => g.selectAll('.tick line').attr('stroke', '#E5E9F0'))
  .call(g => g.select('.domain').remove());
svg.append('g').selectAll('rect').data(data).join('rect')
  .attr('x', d => x(d.key)).attr('y', d => y(d.value))
  .attr('width', x.bandwidth()).attr('height', d => y(0) - y(d.value))
  .attr('fill', PALETTE[0])
  .append('title').text(d => `${d.key}: ${lib.format(',.0f')(d.value)}`);
svg.append('g').selectAll('text').data(data).join('text')
  .attr('x', d => x(d.key) + x.bandwidth() / 2).attr('y', d => y(d.value) - 6)
  .attr('text-anchor', 'middle').attr('font-size', 11).attr('fill', '#333F4F')
  .text(d => lib.format('.3s')(d.value));
```
Adapt: swap `region` and `revenue` for the session's columns; for a trend use `lib.scaleUtc` on parsed dates and `lib.line()`.
